# Project Contract

## Title

LLM-Based Agentic AI for Tool Selection and Multi-Step Execution in Local Image Management

## Aim

To implement and evaluate a lightweight LLM-based agent for tool selection and multi-step execution in local image management.

## Core Tools

1. Retrieve images by date.
2. Create a destination folder.
3. Copy selected images.

## Evaluation Metrics

- Tool-selection accuracy
- Argument correctness
- Task-completion rate
- Error-handling behaviour

## Initial Scope

- Windows environment
- One designated image directory
- Pretrained lightweight language model
- Predefined Python functions
- Single-tool and multi-step tasks
- Controlled test dataset

## Excluded Scope

- Image-content recognition
- Model training
- Unrestricted filesystem access
- Permanent file deletion
- Automatic modification of final thesis content

## Agent Rules

- Work only inside this repository.
- Never modify the main Git branch directly after the initial setup.
- Never delete source images.
- Never invent citations or experimental results.
- Record every experiment and failure.
- Run relevant tests after every code change.
- Request approval before changing scope, methodology, dependencies, or evaluation data.
- Propose thesis changes as drafts for human review.

## Completion Rule

A task is complete only when:

1. The implementation exists.
2. Relevant tests pass.
3. Results are recorded.
4. Any thesis-related claim is linked to evidence.
